# 台灣鳥類觀察：撿到鳥怎麼辦？

幫助民眾在遇到落地或受傷的鳥時做出正確處理，並用台灣近期的觀察資料判斷鳥屬於哪個類群，給出對應的救傷提醒。

救傷中心收到的鳥，有四到六成是沒受傷、還在學飛的幼鳥，被好心的人撿走了；網路上的處理方式又很分散，甚至互相矛盾。這個專案把公開的救傷資訊查證、整理成有出處的指引，再用 [iNaturalist](https://www.inaturalist.org/) 的研究級觀察資料，讓網站知道每隻鳥屬於猛禽、鷺鷥類、早熟型水鳥或鴿子，給出不同的注意事項。

這是程式課期中專案，技術上練習 API、MySQL、PyMySQL 與前端網頁的整合。

## 功能

- **首頁就是救傷入口**：最上方是救傷專線撥號按鈕，下面直接是三張情境卡片，不用先知道鳥名
- **遇到牠怎麼辦？**
  - 雛鳥、幼鳥、受傷或生病三種情境的做法，附分辨特徵對照表（首頁和每隻鳥的詳細視窗都有）
  - 依鳥的類群顯示黃色提醒框：猛禽、鷺鷥類、早熟型水鳥、鴿子（每隻鳥最多一個）
  - 救傷專線（林業保育署 0800-000-930、1999、1959）與資料來源
- **找出是什麼鳥**：近期觀察紀錄的照片卡片，可搜尋鳥名、學名或縣市；屬於特別類群的鳥會顯示黃色標籤
- **詳細視窗**：大圖、分類、地點、照片授權、原始紀錄連結，以及這種鳥的救傷提醒
- **統計查詢**（stats.sql）：常見鳥種、各目、各縣市、每日紀錄數、資料品質檢查

## 資料流程

```
iNaturalist API
      │  fetch.py：抓取 → 查目科 → 清理 → 去重寫入
      ▼
    MySQL（observations、fetch_log）
      ├─ stats.sql：統計與資料品質檢查
      │  export.py：讀出 → 整理 → 匯出
      ▼
  web/data.js
      │
      ▼
    網頁（index.html、style.css、script.js）
```

## 環境需求

- Python 3.12
- MySQL（建議搭配 MySQL Workbench）
- Git
- 瀏覽器（Chrome 等）

## 安裝與執行

**1. 下載專案、建立虛擬環境**
```
git clone https://github.com/amykjo/taiwan-birds.git
cd taiwan-birds
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
Windows 若出現「已停用指令碼執行」，先執行
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` 再啟動（只對目前的視窗有效）。

**2. 設定資料庫連線**

複製 `config.example.py`，改名為 `config.py`，填入自己電腦的 MySQL 密碼。`config.py` 已寫在 `.gitignore`，不會上傳。

**3. 建立資料表**

在 MySQL Workbench 開啟 `schema.sql`，按閃電圖示執行。

**4. 抓取資料**
```
python fetch.py
```
目前設定抓 10 頁、每頁 200 筆，約 2000 筆。重複執行也沒關係，已存過的紀錄會自動跳過；每次執行結果記在 `fetch_log` 資料表。

**5. 匯出給網頁**
```
python export.py
```

**6. 開啟網頁**

直接雙擊 `web/index.html`，不需要架伺服器（照片需要網路才會顯示）。

## 資料說明

**抓取條件**（fetch.py）
- 地點：台灣（iNaturalist place_id `7887`，國家層級）
- 類群：鳥類；品質：研究級（多位使用者同意鑑定結果，相對可靠，但不保證完全正確）
- 照片授權：只抓 `cc0`、`cc-by`、`cc-by-nc`，可以公開展示的照片
- 語言：`zh-TW`，回傳中文名

**目前資料**：2000 筆、216 種鳥，觀察日期 2026-10-10 至 10-24。缺中文名、缺目、缺科皆為 0 筆。

**資料表**
- `observations`：一列代表一筆觀察紀錄，主鍵為 iNaturalist 觀察編號 `obs_id`，搭配 `INSERT IGNORE` 去重
- `fetch_log`：一列代表執行一次抓取程式的結果（拿到、過濾、新增筆數）

**目、科**：API 只回傳祖先分類的編號，程式再用 taxa 端點查出目、科的中文名。分類採用 iNaturalist 的分類系統，可能與《臺灣鳥類名錄》不同（例如鷺科在此歸於鵜形目）。

## 已知限制

- **觀察偏誤**：數字是「觀察紀錄數」，反映的是觀察者在哪裡、什麼時候拍，不等於鳥的族群數量。例如十月灰面鵟鷹過境期間，恆春、滿州的紀錄特別多。400 筆時看起來週末是平日兩倍，擴容到 2000 筆後這個現象就不明顯了。
- **資料範圍**：程式抓的是「最新的 2000 筆」，最舊的那一天可能沒抓完；最近幾天的紀錄較少，因為研究級需要時間等別人鑑定。
- **可能包含死亡個體**：iNaturalist 排除死亡個體的查詢參數測試無效。
- **縣市判斷**：縣市是從地點描述文字找「XX縣／XX市」，英文地址或只寫「Taiwan」的判斷不出來（約 39%）；部分鄉鎮市（如竹北市）會被誤當成縣市。
- **重複上傳**：少數紀錄是不同帳號上傳同一張照片（約 0.25%），在 iNaturalist 上是不同紀錄，主鍵去重擋不下來。同日同地的大量紀錄多半是真實的賞鳥熱點，自動合併會誤刪，所以不處理。
- **中文名**：來自 iNaturalist 社群登錄；沒有中文名的會改顯示學名（例如燕鴴科顯示為 Glareolidae）。
- **類群提醒的範圍**：只有找得到來源支持「處理方式不同」的類群才加黃色框。雉鴴科（水雉）、彩鷸科的寶寶也是早熟型，但查無來源，所以只顯示一般做法。

## 關於「遇到牠怎麼辦？」

這部分是一般性整理，**請以專業救傷單位的指示為準**。內容依據公開資料整理，尚未經救傷專業人員審閱。

- 每一條建議都有出處，台灣來源優先（台北市野鳥學會、林業保育署、農業部、各縣市動保處、中華民國野鳥學會等），國外來源只用來破解迷思或補充原因。
- 台灣來源彼此矛盾的內容不寫（例如給水方法、臨時鳥巢），交由救傷單位電話指導。
- 網頁上可以展開「查看資料來源」，列出該頁內容用到的來源。

遇到需要幫助的野鳥：林業保育署 24 小時免付費專線 **0800-000-930**，或撥 **1999** 縣市專線、**1959** 動保專線。各縣市救傷單位見[中華民國野鳥學會通訊錄](https://www.bird.org.tw/basicpage/117)。
